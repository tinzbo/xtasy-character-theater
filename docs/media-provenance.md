## Compiled media

Every public clip is compiled from original generated artwork, authored Chinese dialogue and **Kokoro-82M-v1.1-zh** local neural narration. The camera motion is deterministic. Chinese captions use actual per-sentence generated durations and are embedded in MP4 and shipped as SRT/VTT. No real person likeness or cloned voice was used. Ordinary playback uses committed assets without generation credentials.

Model and selected voices use the publisher's Apache-2.0 license. Generation is pinned to revision `01e7505bd6a7a2ac4975463114c3a7650a9f7218`; model SHA-256, voice identifiers and all synthesis parameters are recorded in `data/tts-config.json`. Each clip also records source-text, voice-pack, generated-audio and video checksums in `data/media-manifest.json`.

See [third-party notices](../THIRD_PARTY_NOTICES.md) for model provenance and license, and [media rebuilding instructions](media-build.md) for the isolated Python / FFmpeg workflow. Verify the committed artifacts with `npm run media:check`.
